## English

SynBioPath is a curated navigation site for synthetic biology research. It helps lab members quickly find bioinformatics tools, standard operating procedures (SOPs) for reagents and kits, and instrument-related references in one place.

### Live site

Open in your browser (no install required):

**https://wyplayground.github.io/websitedesign/synbiopath/**

### Features

- **Tool catalog** — Browse and search computational tools by category and tags.
- **Operation manuals (SOP)** — Reagent and kit instructions with overview steps and links to full PDF documents.
- **Lab instruments** — Reference information for common equipment.
- **Favorites** — Save tools locally in your browser (account sync planned for a later release).

### How to use

1. Open the live site above.
2. Use the top navigation: **Tools**, **Operation manuals**, or **Instruments**.
3. On **Tools**, filter by category or search by name; click a card for details and external links.
4. On **Operation manuals**, pick a document from the sidebar; read the summary and use **完整PDF链接** to open the full PDF.
5. Use the star icon on a tool to add it to **My favorites** (stored in this browser only).

## 中文说明

SynBioPath（合成生物学科研导航）用于集中展示生信工具、试剂盒操作说明（SOP）与仪器相关信息，方便实验室成员快速查阅。

### 在线访问

在浏览器中打开（无需安装）：

**https://wyplayground.github.io/websitedesign/synbiopath/**

### 功能

- **工具导航** — 按分类、标签浏览与检索生信工具。
- **操作说明** — 试剂与试剂盒 SOP，含操作概览及完整 PDF 链接。
- **仪器说明** — 常用仪器相关参考信息。
- **我的收藏** — 在浏览器本地收藏工具（后续计划支持账号云同步）。

### 使用步骤

1. 打开上方在线地址。
2. 使用顶部导航：**工具**、**操作说明**、**仪器**。
3. 在 **工具** 页按分类筛选或搜索名称；点击卡片查看详情与外链。
4. 在 **操作说明** 左侧选择文档；阅读摘要后点击 **完整PDF链接** 查看完整 PDF。
5. 点击工具卡片上的星标可加入 **我的收藏**（仅保存在当前浏览器）。
